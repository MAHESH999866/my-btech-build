# Durga MaheswaraRao B Tech CSE Portfolio

Build a modern, clean, and professional personal portfolio website for a Final-year B.Tech Computer Science student. The design should look like a real student's portfolio, not like a corporate company website. It should be simple, attractive, responsive, and professional with smooth animations and a good user experience.

General Requirements

 Frontend only (no backend implementation).

 Use React + TypeScript + Tailwind CSS.

 Fully responsive for desktop, tablet, and mobile.

 Professional but simple color scheme (white, black, blue, gray).

 Smooth scrolling and subtle animations.

 Dark mode support.

 Modern UI with rounded cards and shadows.

 Good spacing and typography.

 Add icons wherever appropriate.

Important Instructions

 Make the website look like it was created by a genuine Final-year B.Tech student who is learning and growing, not like an advanced corporate portfolio.

 Keep the design simple, elegant, and professional.

 Avoid excessive animations and unnecessary complexity.

 Use realistic placeholder data that can easily be replaced later.

 Frontend only for now; no backend or database integration.

 Write maintainable and well-structured code.

 Follow modern UI/UX principles.

 Ensure the website is deployment-ready.
